# Exact Age Calculator

A clean, responsive web application that calculates a user's exact age in **years, months, and days** from their date of birth, along with total days lived and a countdown to their next birthday.

## Features
- **Exact Age Breakdown:** Accurately calculates age in years, months, and days while accounting for leap years and varying month lengths.
- **Custom Target Date:** Defaults to today's date, with an option to calculate age on any past or future date.
- **Total Days Lived:** Displays the total number of days elapsed since birth.
- **Next Birthday Countdown:** Shows how many days remain until the next birthday and which day of the week it falls on.
- **Input Validation:** Prevents invalid submissions such as empty fields or birth dates set after the target date.

## Tech Stack
- **HTML5:** Semantic structure and accessible form controls
- **CSS3:** Responsive card layout using CSS Grid and Flexbox
- **Vanilla JavaScript (ES6+):** DOM manipulation, date arithmetic, and form validation

## How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com
   ```
2. Navigate to the project folder:
   ```bash
   cd age-calculator
   ```
3. Open `index.html` directly in any web browser.
